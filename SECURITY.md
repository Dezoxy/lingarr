# Security policy

This is a fork of [lingarr-translate/lingarr](https://github.com/lingarr-translate/lingarr) that only
adds the Anthropic batch fix described in [FORK.md](FORK.md).

- Vulnerabilities in the fork's changes or its CI: report them privately through
  [GitHub private vulnerability reporting](https://github.com/Dezoxy/lingarr/security/advisories/new).
- Vulnerabilities in Lingarr itself: report them to the upstream project.

Please do not open public issues for security problems.
